# eurodao_environment_description

Package ROS 2 dedie aux meshes de l'environnement de travail.

Contenu actuel:
- `meshes/stl/01-bras-support`
- `meshes/stl/02-mur`
- `meshes/stl/03-table-travail`
- `meshes/stl/04-armoire-noir`
- `meshes/stl/05-armoire-blanche`

Ce package sert de base pour la scene finale. Les prochains fichiers de scene ou de description
de l'environnement devront etre references depuis ce package plutot que depuis le dossier racine
`Modélisation-environnement`.
