\chapter{Teleoperate in Simulation}
\label{chap:touch}

The 3D Systems Touch is used to generate Cartesian targets for the simulated
robot. Install and validate the device before starting this chapter; the full
procedure is in \cref{app:openhaptics}. The Touch must be plugged in, and no
other OpenHaptics program may own it while the teleoperation launcher is active.

\section{The Project Teleoperation Loop}

A practical teleoperation system separates device input, target generation,
low-level control, and recording:

The recorder observes the same simulation while the operator controls it. This
keeps the teleoperation loop and the saved demonstrations synchronized.

\section{How the Touch Motion Is Mapped}

The physical coordinates of a desktop device generally have no useful absolute
relationship with the robot base. Use differential motion:

\begin{equation}
  \Delta p_{robot} = s_p M_p
  \left(p^{device}_{t}-p^{device}_{t-1}\right),
\end{equation}

where $M_p$ maps axes and $s_p$ sets workspace scale. The first valid device
pose becomes a reference and produces no robot movement. This prevents the
initial jump that would occur if the device pose were interpreted as an
absolute robot target.

Test one translation and one rotation axis at a time. If an axis is reversed,
correct the mapping in the code instead of compensating during demonstrations.

For Cartesian velocity control, a common structure is:

\begin{equation}
  v_{des} =
  \begin{bmatrix}K_p e_p & K_r e_r\end{bmatrix}^{T},
  \qquad
  \dot q = J^{\#}(q)v_{des},
\end{equation}

where $e_p$ and $e_r$ are pose errors and $J^{\#}$ is a damped Jacobian
pseudoinverse. The controller then applies joint-velocity and safety limits.

Target smoothing can reduce abrupt hand motion:

\begin{equation}
  x_f(t)=(1-\alpha)x_f(t-1)+\alpha x_{raw}(t).
\end{equation}

A large $\alpha$ follows the hand more closely; a small value smooths motion but
adds lag. Change workspace scale, target-speed limit, smoothing, and controller
gain one at a time. The robot must be responsive enough for small corrections
before any data are recorded.

\section{Launch the Complete Simulation Loop}

Close standalone Touch diagnostics first, then run:

\begin{lstlisting}[language=bash]
cd "$HOME/Stage_Lirmm/Diffusion-model-isaacsim"
conda activate microwave_dp
./launch_all.sh
\end{lstlisting}

The wrapper checks required files and Python modules, starts the ROS~2 Touch
node, waits for \filepath{/touch/pose}, and then opens the MuJoCo teleoperation
program. Both processes stop when \filepath{Ctrl+C} is pressed in this terminal.
Touch logs are written to
\filepath{/tmp/diffusion_policy_touch_driver.log} by default.

Before recording, move the stylus slowly and test all axes. Confirm that:

\begin{itemize}
  \item the first received Touch pose does not make the robot jump;
  \item translations and rotations follow the expected directions;
  \item the gripper buttons produce the expected simulated command;
  \item the robot remains stable when the Touch is held still;
  \item the wrist and global views remain live throughout the motion.
\end{itemize}

\section{Fix Responsiveness Before Recording}

If small corrections are difficult, do not compensate by making large hand
motions. Check the newest ROS target is consumed, then inspect position scale,
target filtering, servo gains, joint-velocity limits, and simulation rate. A
slow controller records delayed corrective motion that the future policy will
learn.

\begin{warningbox}[Common Touch launch failures]
If \filepath{/touch/pose} never appears, run the vendor diagnostic and ROS topic
test from \cref{app:openhaptics}. If the device is reported as busy, close every
other OpenHaptics example or Touch ROS node. If the first workspace build fails,
verify \filepath{OPENHAPTICS_ROOT} before rebuilding.
\end{warningbox}

\begin{checkpointbox}[Teleoperation ready]
The simulated robot follows every mapped axis without jumps, lag is low enough
for precise corrections, the gripper behaves consistently, and both policy
camera views remain live during a complete manual task.
\end{checkpointbox}
