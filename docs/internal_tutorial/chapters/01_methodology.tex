\chapter{MuJoCo Fundamentals}
\label{chap:simulation}

This guide follows the shortest useful path through the project: open and
validate the MuJoCo task, control it with the 3D Systems Touch, record and
inspect demonstrations, train a policy, and execute the checkpoint. It assumes
basic knowledge of Python, ROS~2, and robotics. Installation commands are kept
in \filepath{README_ENV.md}; the complete Touch installation is reproduced in
\cref{app:openhaptics}.

MuJoCo reads an XML description of a mechanical system and numerically advances
its state through time. In this project it provides the UR10, microwave scene,
contacts, cameras, robot state, and control interface needed to test the full
learning workflow without moving physical hardware.

\section{Activate the local environment}

From a new terminal:

\begin{lstlisting}[language=bash]
cd "$HOME/Stage_Lirmm/Diffusion-model-isaacsim"
conda activate microwave_dp
python --version
python -c "import mujoco, numpy, cv2; print('Local environment: OK')"
\end{lstlisting}

If \filepath{microwave_dp} does not exist, stop and follow
\filepath{README_ENV.md}. Do not install packages one by one into an unrelated
environment; the resulting versions may no longer match the project.

\begin{checkpointbox}[Local pre-flight]
The repository is complete, \filepath{microwave_dp} activates without an
error, and Python can import MuJoCo, OpenCV, NumPy, Pinocchio, ROS~2, and the
local \filepath{diffusion_policy} package.
\end{checkpointbox}
